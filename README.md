# java-lotto-precourse

##  기능 목록

### 1. 로또 구매
- [ ] 로또 구입 금액을 입력받는다.
- [ ] (예외) 구입 금액이 1,000원 단위가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] (예외) 구입 금액이 숫자가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] 구입 금액에 해당하는 만큼 로또를 발행한다.
- [ ] 발행된 로또의 개수를 출력한다.
- [ ] 발행된 로또 번호(오름차순 정렬) 목록을 출력한다.

### 2. 당첨 번호 입력
- [ ] 당첨 번호(6개)를 쉼표(,) 기준으로 입력받는다.
- [ ] (예외) 당첨 번호가 6개가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] (예외) 당첨 번호에 중복된 숫자가 있는 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] (예외) 당첨 번호가 1~45 범위를 벗어난 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] (예외) 당첨 번호가 숫자가 아닌 값을 포함한 경우 `IllegalArgumentException`을 발생시킨다.

### 3. 보너스 번호 입력
- [ ] 보너스 번호(1개)를 입력받는다.
- [ ] (예외) 보너스 번호가 1~45 범위를 벗어난 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] (예외) 보너스 번호가 당첨 번호와 중복되는 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] (예외) 보너스 번호가 숫자가 아닌 경우 `IllegalArgumentException`을 발생시킨다.

### 4. 당첨 통계 및 수익률 계산
- [ ] 구매한 로또와 당첨 번호를 비교하여 당첨 등수(Rank)를 결정한다.
    - [ ] 1등: 6개 번호 일치
    - [ ] 2등: 5개 번호 + 보너스 번호 일치
    - [ ] 3등: 5개 번호 일치
    - [ ] 4등: 4개 번호 일치
    - [ ] 5등: 3개 번호 일치
- [ ] 각 등수별 당첨 개수를 집계한다.
- [ ] 총 당첨금을 계산한다.
- [ ] 총 수익률을 계산한다. (수익률은 소수점 둘째 자리에서 반올림)

### 5. 결과 출력
- [ ] 당첨 통계 결과를 형식에 맞게 출력한다.
    - (예: `3개 일치 (5,000원) - 1개`)
- [ ] 총 수익률을 형식에 맞게 출력한다.
    - (예: `총 수익률은 62.5%입니다.`)
